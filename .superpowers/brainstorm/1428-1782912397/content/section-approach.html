Section Baru: Rebrand Studio + Marketing Kit

3 approach untuk dedicated section sebelum pricing

A

Split Cluster — 2 Card Side-by-Side

Cluster kiri: Rebrand Studio (workspace + scope + auto-fill). Cluster kanan: Marketing Kit (prompt blocks). Kedua card setinggi, masing-masing punya icon, headline, 3-4 sub-feature bullet, dan micro-illustration.

Preview: Split Cluster
🎨

Rebrand Studio

Ubah identitas app jadi brand Anda

  • Browser-based workspace — tanpa install
  • 3 scope: Quick / Repositioning / Full Launch
  • Auto-derive brand positioning
📋

Marketing Kit

Bahan mulai jual hari pertama

  • Headline & CTA selling siap pakai
  • Ide konten promosi & angle campaign
  • Bahan awal sales page & launch checklist

Pros

  • Visual balance — kedua cluster setara
  • Scannable — buyer lihat 2 value pillar langsung

Cons

  • Mobile: jadi stack vertikal, bisa panjang
  • Kurang emphasize satu cluster di atas lain
B

Stacked Showcase — Rebrand Atas, MK Bawah

Section header + kicker. Lalu Rebrand Studio card full-width (hero treatment — lebih besar, ada scope picker visual). Di bawah: Marketing Kit card lebih compact. Hirarki: Rebrand = main attraction, MK = supporting asset.

C

Feature Grid — 2x2 Card Grid

2x2 grid: Rebrand Studio (besar, kiri atas), Marketing Kit (kanan atas), 3 Scope (kiri bawah), Brand Derive (kanan bawah). Semua fitur punya card sendiri tapi tetap dalam 1 section. Lebih detail, lebih "feature tour".
