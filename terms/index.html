Ketentuan Layanan

Terakhir diperbarui: Juni 2026

1. Layanan

White-Label AI App Vault menyediakan lisensi white-label untuk 13 aplikasi AI berbasis Canvas. Pembeli memperoleh hak untuk merebrand, mengemas, dan menjual akses aplikasi tersebut kepada end user mereka sendiri.

2. Hak Penggunaan

Pembeli berhak:

  • Mengubah nama, identitas visual, positioning, dan copy aplikasi
  • Menjual akses aplikasi kepada end user, member komunitas, atau klien
  • Menggunakan aplikasi sebagai bonus program atau client portal

Pembeli tidak berhak:

  • Menjual file inti, template, atau source code aplikasi
  • Meneruskan hak white-label kepada pihak lain tanpa lisensi terpisah

3. Tanggung Jawab

Produk yang dijual menggunakan lisensi white-label sepenuhnya menjadi tanggung jawab pembeli dalam hal konten, positioning, kepatuhan iklan, dan kepuasan pelanggan akhir.

4. Pembayaran

Lisensi diberikan setelah pembayaran lunas. Tidak ada sistem refund otomatis; pengembalian dana dipertimbangkan secara kasus per kasus.
